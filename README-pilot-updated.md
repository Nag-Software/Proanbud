# Proanbud Pilot Landing Page

Dette er en komplett pilot-landingside for Proanbud som matcher designet og stilen til hjemmesiden.

## Design og stil

Siden bruker samme:
- Header/navbar som hjemmesiden med Logo komponent
- Fargepalett (#82ffb2 grønn, #82b2ff blå)
- Gradient bakgrunn: bg-gradient-to-br from-white via-[#82ffb2]/5 to-[#82b2ff]/5
- Footer komponent
- Typografi og spacing
- CTA-knapper med samme styling

## Struktur

- `src/app/pilot/page.tsx`: Hovedside med samme header/footer som hjemmesiden
- `src/components/Hero.jsx`: Oppdatert Hero som matcher hjemmesidens stil
- `src/components/SignupForm.jsx`: Skjema med oppdatert styling
- Andre komponenter som før

## Oppdatering av tall etter pilot

Samme som før - oppdater `SUGGESTED_METRICS` i relevante filer.

## Analytics og tracking

Samme PostHog events som før.

## Deploy

Samme som hjemmesiden - bygg og deploy som Next.js app.
